# Interface direction

Student job: read a difficult lecture and return to an explanation after a wrong answer. Source access and the current paragraph have priority; imported media may be missing, untimed, or awaiting captions. The interface must be keyboard usable, mobile readable, and clear about unresolved evidence.

Three directions considered: (1) a textbook with a floating player, prioritizing immersion but hiding the source; (2) a timeline-first editing studio, precise but too much like video software; (3) an editorial reading room with a persistent source panel and a calm book. Select the third because its layout expresses the central relationship without explaining it repeatedly.

Use an ivory canvas, forest-green controls, thin warm rules, large Newsreader headings, and DM Sans utility text. Desktop navigation is a narrow rail, source panel left, manuscript right. Mobile stacks the source above the book and offers a sticky Source button. The landing uses an original botanical diagram and a dimensional CSS book, not a stock AI illustration. Consolidate outline and print controls into panels; remove decorative percentages, artificial processing animations, and redundant cards.

Validate the real player, wrong-answer recovery, evidence states, imported-source recovery, and exports at 390 and 1280 pixels before considering the design finished.
